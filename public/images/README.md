# Procedência das imagens

- `hero-cosmetics.webp`: composição fotográfica sintética original gerada para o protótipo Agylli em 5 de novembro de 2026. Embalagens e produtos são fictícios. O original de geração é mantido fora do checkout em `/workspace/generated_images/`; o site utiliza a versão WebP local otimizada.
- `skincare.svg`, `haircare.svg`, `perfume.svg`, `makeup.svg`: ilustrações vetoriais originais criadas para este projeto. Marcam categorias e produtos demonstrativos, sem reproduzir embalagens reais de terceiros.
- `src/app/icon.svg`: ícone provisório original com a letra A.
- Fontes DM Sans e DM Serif Display: distribuídas pelos pacotes Fontsource, sob licenças OFL presentes nos respectivos pacotes. Os arquivos são servidos localmente.

Nenhum ativo foi obtido da Sallve. A consulta à referência visual e ao domínio de fotografias externas não foi possível pela política de rede; o projeto não depende desses domínios. Substituir os conceitos por fotografias reais aprovadas antes de apresentar um catálogo comercial.
